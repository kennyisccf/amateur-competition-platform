\# 乐赛 (Lesai) 页面框架与跳转流转



\## 1. 全局分栏架构 (Layout)

除登录注册页外，全站核心业务层采用标准 \*\*左右分栏主框架\*\*：

\* \*\*左侧固定栏 (250px)\*\*：Logo 区域 + 动态角色功能菜单（蓝底白字）。

\* \*\*右侧主体区 (自适应)\*\*：

&#x20; \* \*\*顶部条 (Header)\*\*：面包屑路径 + 用户快捷入口 + 全局强制性 \*\*“← 返回赛事大厅”\*\* 按钮。

&#x20; \* \*\*内容容器 (Container)\*\*：独立滚动，承载具体业务卡片与数据表格。



\## 2. 核心界面骨架与流转逻辑



\### 2.1 登录注册页 (AuthUI)

\* \*\*结构\*\*：全屏沉浸。左侧为品牌视觉区；右侧为毛玻璃卡片（含三角色切换标签、账号密码、图形验证码安全组件）。

\* \*\*流转\*\*：点击登录 -> 校验成功 -> `LoginController` 路由单向分发至 -> \*\*赛事大厅 (`TournamentHallUI`)\*\*。



\### 2.2 赛事大厅 (TournamentHallUI) \[核心中枢]

\* \*\*结构\*\*：顶部为带渐变色 Hero 搜索框及药丸标签筛选器；下方为主体网格，部署高颜值巨型赛事海报卡片（显示名称、品类标签、报名进度）。

\* \*\*流转\*\*：作为系统的流量分发核心。\*\*规范要求：所有二级子页面必须能通过顶部或取消按钮双向流转回到大厅。\*\*



\### 2.3 赛事详情与报名页 (RegDetailUI)

\* \*\*结构\*\*：左侧 (2/3) 赛事说明文档区（展示规则、时间、地点、奖金）；右侧 (1/3) 为固定悬浮的报名申请表单（提交自动触发大厅跳转）。



\### 2.4 赛事创建配置页 (CreateTournamentUI)

\* \*\*结构\*\*：单列居中表单卡片。自上而下分为：基础资料组、赛事属性（公开/私人单选）、赛制参数下拉框、长文本描述域。

\* \*\*流转\*\*：提交后触发管理员审核工作流并返回大厅；取消则直接关闭。



\### 2.5 主办方控制台 (OrganizerConsoleUI)

\* \*\*结构\*\*：顶部三列统计看板（当前赛事、报名人数、待办数）；下方为垂直堆叠的数据表格（表格一：选手资格审批工作流；表格二：实时对局比分录入公示）。



\### 2.6 个人运动档案 (ProfileUI)

\* \*\*结构\*\*：左侧为选手数字名片（头像、累计积分、全站排名、荣誉徽章墙）；右侧为时间轴形式的历史参赛轨迹列表及基础资料修改入口。
