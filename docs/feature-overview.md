# 乐赛功能说明文档

## 1. 功能定位

乐赛面向业余赛事组织场景，核心功能不是单点报名，而是围绕赛事生命周期形成闭环：

```text
赛事创建 -> 审核发布 -> 报名参与 -> 名单审核 -> 抽签排赛 -> 赛程推进 -> 结果归档 -> 积分/通知/档案沉淀
```

## 2. 角色模型

系统使用三类角色：

| 角色 | 代码 | 核心职责 |
| --- | --- | --- |
| 参赛者 | `PLAYER` | 找比赛、报名、查看通知、查看赛程与个人档案 |
| 主办方 | `ORGANIZER` | 创建赛事、审核报名、维护名单、生成赛程、录入结果 |
| 管理员 | `ADMIN` | 审核公开赛事、管理用户、平台风控、批量数据维护 |

前端通过 Vue Router 路由守卫限制页面访问，后端通过 `login_required` 和 `role_required` 装饰器控制接口权限。管理员拥有更高权限，可进入后台管理页面并操作平台数据。

## 3. 参赛者功能

### 3.1 赛事大厅

- 查看公开赛事和可见赛事。
- 按赛事类型、状态、关键词、赛事编号筛选。
- 支持收藏关注赛事。
- 赛事卡片展示缩图、状态、人数、时间、地点和编号。

### 3.2 赛事详情与报名

- 查看赛事规则、奖励、时间、地点、主办方和报名进度。
- 支持个人报名和战队报名。
- 私人赛事需填写邀请码。
- 后端校验重复报名、人数上限、赛事状态和参赛账号。

### 3.3 个人运动档案

- 展示用户编号 `U000001` 格式。
- 展示积分、参赛记录、报名状态和历史成绩。
- 支持隐藏/显示部分报名记录。

### 3.4 好友与通知

- 支持通过用户名、昵称或用户编号搜索好友。
- 支持好友申请、通过、拒绝、删除。
- 好友之间可以发送聊天消息。
- 通知中心汇总好友申请、聊天未读、赛事审核结果和报名审核结果。

## 4. 主办方功能

### 4.1 赛事创建与编辑

- 创建公开或私人赛事。
- 设置赛事类型、地点、描述、人数上限、奖励、起止时间。
- 选择默认缩图或上传本地缩图。
- 私人赛事自动生成邀请码。

### 4.2 报名管理

- 查看赛事报名名单。
- 通过或驳回报名。
- 支持批量删除报名记录。
- 支持管理员/主办方强制添加参赛者。
- 批量生成测试参赛者，可选择是否随机积分。

### 4.3 赛程管理

- 读取审核通过的参赛者。
- 生成单淘汰树。
- 支持种子选手、轮空、晋级、退赛、比分录入和结果撤销。
- 比赛完成后写入排名、积分和个人档案。

## 5. 管理员功能

### 5.1 赛事审核

- 查看待审核公开赛事。
- 审核通过后赛事进入报名中。
- 驳回时填写原因，用户可在通知中心看到结果。

### 5.2 用户治理

- 查看用户列表。
- 创建用户、批量生成用户。
- 封禁/解封用户。
- 删除用户或批量删除用户。

### 5.3 平台数据维护

- 批量创建赛事。
- 批量添加参赛者。
- 查看审核记录和平台统计数据。

## 7. 当前特色功能

- 单淘汰树生成和可视化。
- 种子选手首轮保送逻辑。
- 多人树图动态布局。
- 好友通知即时刷新。
- 默认缩图和本地上传缩图。
- 批量测试数据生成，支持随机积分。
- 用户编号 `U000001`，便于好友搜索和用户识别。
