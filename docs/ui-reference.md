\# 乐赛 (Lesai) UI 视觉参考



\## 1. 架构与 SaaS 控制台参考

\* \*\*Vercel (vercel.com)\*\*

&#x20; \* \*\*参考点\*\*：极致扁平化网格、状态指示灯设计、标准化圆角（8px-12px）。

&#x20; \* \*\*应用\*\*：赛事大厅卡片排版、主办方工作台的数据流转面板。

\* \*\*Taskade / Notion\*\*

&#x20; \* \*\*参考点\*\*：高颜值侧边栏导航、流线型多级菜单高亮状态。

&#x20; \* \*\*应用\*\*：全局左侧导航栏及多角色权限视图渲染。



\## 2. 潮流运动与视觉冲击参考

\* \*\*千岛 (Qiandao / 潮流社区)\*\*

&#x20; \* \*\*参考点\*\*：

&#x20;   1. 顶部宽阔、带亮蓝色发光渐变的搜索区（Hero Section）。

&#x20;   2. 极简药丸形（Pills）多维度滚动筛选标签。

&#x20;   3. 赛事大卡片设计（海报图 + 底部白色数据面板 + 压暗图层上的巨型艺术字标题）。

&#x20; \* \*\*应用\*\*：重构后的赛事大厅 (TournamentHallUI) 核心视觉。



\## 3. 业务组件与数据可视化参考

\* \*\*Challonge (challonge.com)\*\*

&#x20; \* \*\*参考点\*\*：自助赛事极其精简的报名表单、比分录入表、标准淘汰赛对阵图（Bracket）。

&#x20; \* \*\*应用\*\*：赛事详情及报名页 (RegDetailUI)、创建赛事页 (CreateTournamentUI)。

\* \*\*Faceit (esports)\*\*

&#x20; \* \*\*参考点\*\*：个人积分、站内排名、多维度胜率数据的雷达图/直方图排版。

&#x20; \* \*\*应用\*\*：个人运动档案 (ProfileUI) 的资产和荣誉墙可视化。
