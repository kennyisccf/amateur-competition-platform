页面骨架与跳转路由

1. 全局布局
左侧栏 (250px): 固定显示 Logo + 根据角色渲染的动态菜单。
右主体 (自适应): Header (强制含“← 返回大厅”入口) + 独立滚动的业务容器。

2. 核心流转
登录页 (AuthUI)
骨架: 全屏左右分栏 (左图右表)。
流转: 鉴权成功 -> 单向进入大厅。
* 赛事大厅 (TournamentHallUI)
  * 骨架: 顶部搜索与标签筛选 + 底部卡片网格。
  * 流转: 全站分发中枢，所有子页面均需闭环返回此处。
* 赛事详情 (RegDetailUI)
  * 骨架: 左 (2/3) 赛事规则长文 + 右 (1/3) 悬浮报名表单。
* 创建赛事 (CreateTournamentUI)
  * 骨架: 居中单列超大表单 (基础信息 -> 赛制参数 -> 详情描述)。
* 控制台 (OrganizerConsoleUI)
  * 骨架: 顶部三大核心指标统计 + 底部垂直堆叠的数据表格 (审批表、计分表)。
* 选手档案 (ProfileUI)
  * 骨架: 左数字名片 (头像/积分/徽章墙) + 右动态轨迹 (时间轴/资料修改)。
