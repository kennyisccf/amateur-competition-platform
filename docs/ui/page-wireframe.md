# 乐赛页面结构与路由说明

## 1. 全局布局

业务页面统一使用左侧导航 + 右侧内容区：

- 左侧：Logo、角色相关菜单、退出登录。
- 右侧：具体业务页面。
- 消息通知菜单展示角标。
- 未登录用户访问业务路由会跳转登录页。

## 2. 公开页面

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/login` | 登录页 | 账号、密码、验证码、动态背景 |
| `/register` | 注册页 | 注册表单、同登录页风格背景 |

## 3. 核心业务页面

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/home` | 赛事大厅 | 赛事搜索、筛选、卡片展示 |
| `/event-detail/:id` | 赛事详情 | 赛事规则、状态、报名入口、淘汰树预览 |
| `/event-register/:id` | 报名页面 | 个人/战队报名 |
| `/profile` | 个人档案 | 用户资料、积分、报名记录 |
| `/notifications` | 消息通知 | 待办、好友、赛事/报名通知 |
| `/friends` | 好友系统 | 搜索、申请、聊天、删除好友 |

## 4. 主办方/管理员业务页面

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/create` | 创建赛事 | 赛事基础信息、时间、缩图、公开/私人 |
| `/workbench` | 赛事工作台 | 当前用户可管理赛事 |
| `/registration-manage` | 报名管理 | 审核报名、批量生成、抽签淘汰树 |
| `/competition-edit/:id` | 编辑赛事 | 修改赛事信息 |
| `/admin-review` | 审核与风控 | 管理员赛事审核、用户治理、批量管理 |
| `/forbidden` | 无权限页 | 越权访问提示 |

## 5. 核心跳转流程

### 5.1 参赛者流程

```text
登录 -> 赛事大厅 -> 赛事详情 -> 报名 -> 消息通知 -> 个人档案
```

### 5.2 主办方流程

```text
登录 -> 赛事工作台 -> 创建/编辑赛事 -> 报名管理 -> 生成淘汰树 -> 录入结果
```

### 5.3 管理员流程

```text
登录 -> 审核与风控 -> 赛事审核 -> 用户管理 -> 审核记录/统计
```

## 6. 淘汰树嵌入位置

淘汰树不是独立路由，而是组件：

```text
src/components/CompetitionBracket.vue
```

它主要嵌入：

- `EventDetail.vue`：参赛者查看赛程。
- `RegistrationManage.vue`：主办方维护赛程。
