UI 视觉与组件规范

1. 色彩规范
品牌蓝: `#1E90FF` (按钮、主色调)
  交互蓝: `#187bcd` (Hover 状态)
  发光色: `rgba(30,144,255,0.1)` (Focus 外发光)
  背景色: `#f5f7fb` (全局底色) | **卡片色**: `#FFFFFF` (纯白)
  状态色: 成功 `#2ecc71` | 驳回 `#e74c3c` | 警告 `#f39c12`

2. 字体排版
字体族 : `'PingFang SC', 'Microsoft YaHei', sans-serif`
字体: 大标题 `28-36px` (加粗) | 模块标题 `18-24px` | 正文 `14-15px` | 辅助字 `12px`

3. 核心组件
   按钮: `#1E90FF` 背景，`8px` 圆角，无边框。
   卡片: `#FFFFFF` 背景，`12-16px` 圆角，阴影 `0 4px 15px rgba(0,0,0,0.03)`，Hover 上浮位移。
   输入框: `#fafafa` 背景，`8px` 圆角，Focus 触发蓝边与外发光。
筛选标签: 胶囊型 (`20px` 圆角)，激活为主色白字，未激活为白底灰字。
