# 乐赛 (Lesai) UI 视觉与组件规范

## 1. 设计理念
* **现代扁平化**：纯色块、轻量级圆角、微柔和阴影，拒绝复杂3D纹理。
* **活力与严谨**：明亮品牌蓝搭配大面积留白与暗色调背景（登录页），兼顾运动感与数据清晰度。
* **卡片块化**：核心业务数据全部以卡片形式呈现，提升视觉聚焦度。

## 2. 色彩系统
* **品牌主色**: `#1E90FF` (主要按钮、激活状态、核心强调)
* **主色悬停**: `#187bcd` (按钮 Hover 状态)
* **聚焦发光**: `rgba(30, 144, 255, 0.1)` (输入框 Focus 外发光)
* **全局背景**: `#f5f7fb` (浅灰蓝，用于衬托纯白卡片)
* **面板背景**: `#FFFFFF` (纯白，用于承载内容的卡片)
* **状态功能色**: 
  * 成功/通过: `#2ecc71` 
  * 危险/驳回: `#e74c3c` 
  * 警告/待办: `#f39c12`

## 3. 字体排版
* **字体族**: `'PingFang SC', 'Microsoft YaHei', sans-serif`
* **大厅/登录标题**: `28px - 36px`, 粗体 `700/900`
* **模块/弹窗标题**: `18px - 24px`, 粗体 `700`
* **卡片/表单标题**: `16px`, 粗体
* **正文/表格数据**: `14px - 15px`, 行高 `1.6`
* **标签/辅助备注**: `12px`, 常规体

## 4. 核心组件规范
* **主按钮**: 背景 `#1E90FF`，圆角 `8px`，白字。Hover 时切换为 `#187bcd` 并伴随微小上移与阴影加深。
* **表格动作按钮**: 小尺寸，圆角 `4px`，字号 `12px`，纯色无边框（对应状态功能色）。
* **标准卡片**: 背景 `#FFFFFF`，圆角 `12px - 16px`，基础阴影 `0 4px 15px rgba(0,0,0,0.03)`。Hover 时产生上浮位移。
* **输入框**: 背景 `#fafafa`，边框 `1px solid #ddd`，圆角 `8px`。Focus 时边框变蓝并触发 `3px` 外发光。
* **筛选标签**: 胶囊型（圆角 `20px`）。激活状态下为主色蓝底白字，未激活下为白底灰字。
