# 文档归档区

本目录存放早期设计材料和历史交付资料。归档文件仅用于追溯设计过程，当前功能、接口、数据库和运行方式以根目录 `README.md`、`docs/` 下的 Markdown 文档以及 `database/` 脚本为准。

## 目录说明

| 目录 | 内容 |
| --- | --- |
| `original-design-docs/` | 早期需求、架构、详细设计、UI、测试与展示材料 |

## 维护原则

- 归档资料不直接作为当前实现依据。
- 如果当前系统功能发生变化，应优先更新主文档，而不是修改归档文件。
- 新增归档文件时使用英文小写文件名，避免不同系统下路径兼容问题。
