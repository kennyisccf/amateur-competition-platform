# 文档归档区

本目录存放早期设计材料和历史版本资料。归档文件仅用于追溯设计过程，最终版文档统一存放在 [`../final-submission/`](../final-submission/)，当前功能、接口、数据库和运行方式以根目录 `README.md`、`docs/` 下的 Markdown 文档以及 `database/` 脚本为准。

## 目录说明

| 目录 | 内容 |
| --- | --- |
| [`original-design-docs/`](original-design-docs/) | 保留中文原名的早期需求、架构、详细设计、UI、测试与展示材料 |

## 原始资料

| 文件 | 类型 |
| --- | --- |
| `第14组-软组织系统-软件需求规格说明书.pdf` | 需求规格说明 |
| `第14组-软组织系统-软件体系结构设计.pdf` | 软件体系结构设计 |
| `第14组-软组织系统-用户界面设计.pdf` | 用户界面设计 |
| `第14组-软组织系统-软件详细设计.pdf` | 软件详细设计 |
| `第14组-软组织系统-软件测试.pdf` | 软件测试资料 |
| `第一次PPT.pptx` | 早期展示材料 |

## 维护原则

- 归档资料不直接作为当前实现依据。
- 如果当前系统功能发生变化，应优先更新主文档，而不是修改归档文件。
- 原始资料保留其中文原名，避免文件名与文档内部标题不一致。
