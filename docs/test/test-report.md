## 5. 边界测试

| 场景 | 处理结果 |
| --- | --- |
| 非 2 的幂人数参赛 | 自动计算 `bracket_size` 和 `bye_slots` |
| 种子人数多于轮空位 | 高优先级种子优先轮空 |
| 没有轮空位 | 种子不强制保送 |
| 1 人参赛 | 走特殊边界，避免树图错误 |
| 删除好友后仍有未读消息 | 后端清理非好友未读消息 |
| 登录态失效 | 前端 401 自动跳转登录页 |
| 赛事过期 | 后端执行过期状态处理 |
