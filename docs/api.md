# 接口文档

## 用户模块

### 用户登录
请求地址：/api/user/login  
请求方式：POST  

### 用户注册
请求地址：/api/user/register  
请求方式：POST  

## 赛事模块

### 获取赛事列表
请求地址：/api/competition/list  
请求方式：GET  

### 创建赛事
请求地址：/api/competition/create  
请求方式：POST  

## 报名模块

### 赛事报名
请求地址：/api/registration/create  
请求方式：POST  

## 管理员模块

### 审核赛事
请求地址：/api/admin/audit  
请求方式：POST
