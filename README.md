# \# 乐赛一站式全民赛事组织服务平台

# 

## \## 项目简介

# 

「乐赛」是一个致力于填补专业职业赛事与民间娱乐局之间空白的一站式全民业余赛事组织与成长服务平台。本平台提供从赛事创办、报名参赛、积分计算到终身运动档案的全闭环服务生态，满足参赛选手、赛事主办方与平台管理员的三方需求。

# 

##### \## 技术栈

# 

\* \*\*前端\*\*: Vue 3 + Vite + Element Plus + Vue Router + Pinia + Axios

\* \*\*后端\*\*: Python 3.11 + Django + Django REST Framework (DRF) + SimpleJWT + django-cors-headers

\* \*\*数据库\*\*: MySQL 8.0 

# 

### \## 核心功能模块

# 

# 

1\. \*\*参赛选手端\*\*: 登录注册、赛事大厅浏览与筛选、赛事详情查看、赛事报名、个人档案查看、积分与报名记录展示。

2\. \*\*赛事主办方端\*\*: 创建赛事、我的赛事查看、报名管理、发布赛事通知、更新比赛结果。

3\. \*\*平台管理员端\*\*: 赛事审核、用户管理、用户封禁/解封、审核记录查看。

# 

# 

### \## 最终验收演示顺序

# 

# 

1\. 普通选手登录/注册。

2\. 进入赛事大厅，浏览和筛选赛事。

3\. 进入赛事详情，完成报名。

4\. 进入个人档案，查看报名记录和积分。

5\. 切换主办方账号，创建赛事。

6\. 主办方查看报名选手，发布通知或更新结果。

7\. 切换管理员账号，审核公开赛事。

8\. 管理员查看用户管理，演示封禁/解封。

9\. 展示 GitHub 仓库结构、README、接口文档、测试报告和运行截图。

### \## 开发与分支规范

# 

\* `main` 分支仅作为稳定可运行版本，\*\*严禁直接推送代码到 main\*\*。

\* 组员日常开发请在个人分支进行，命名规范为：`dev/姓名拼音缩写`（例：`dev/zzf`）。

\* 提交信息 (Commit Message) 规范：
