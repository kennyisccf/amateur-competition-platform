# 乐赛一站式全民赛事组织服务平台

## 项目简介
本项目为「乐赛一站式全民赛事组织服务平台」，旨在为业余爱好者提供专业、便捷的赛事组织工具与永久化的个人参赛档案，填补「专业赛事」与「娱乐约局」之间的市场空白。平台支持参赛选手、赛事主办方和平台管理员三类角色。

## 技术栈
* **前端:** Vue3 + Vite + Element Plus + Vue Router + Pinia + Axios
* **后端:** Python 3.11 + Django + Django REST Framework (DRF) + SimpleJWT + django-cors-headers
* **数据库:** MySQL 8.0
